My current MEng research asks how an embodied robot can represent **objects, states, actions, constraints, and reusable task procedures** in a form that supports reliable planning and execution.

The project explores a graph-based representation that combines scene knowledge with procedural memory. The goal is to make long-horizon task execution more compositional: retrieve a relevant task structure, bind it to the current scene, execute it, and verify whether the intended state changes occurred.

### Current focus

- 3D scene and task graph design
- action preconditions, effects, and object capabilities
- reusable procedural memory
- long-horizon task execution and verification
- evaluation in embodied simulation

A related reading/resource collection is available in my [awesome-3D-scene-graphs repository](https://github.com/lazur07/awesome-3D-scene-graphs).
